# zyt-releases

Public release artifacts and Sparkle appcast for [Zyt](https://github.com/thaungsunyein/zyt) — a macOS menu bar app that shows your next meeting and reminds you when it's about to start.

## What lives here

- `appcast.xml` — the Sparkle update feed. Zyt checks this URL automatically to discover new versions.
- GitHub Releases — each tagged release ships a notarised DMG as an asset. Sparkle downloads from those URLs.

## Source code

The Zyt source is private at [github.com/thaungsunyein/zyt](https://github.com/thaungsunyein/zyt). This repo exists only to serve public release artifacts.
